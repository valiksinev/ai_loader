# CLAUDE.md

Проект: веб-сервис сопоставления номенклатуры поставщиков для клиентов 1С:КА 2 (демо).

**Полные требования — в `SPEC.md`. Прочитай его целиком перед началом любой работы.**

## Правила работы

- Работай строго по этапам из `SPEC.md`, раздел 11. Этап 1 (ядро алгоритма без веба) — первым. Не начинай следующий этап, пока не выполнены критерии приёмки текущего.
- Главный принцип алгоритма: ошибка в корзине `auto` хуже, чем лишняя строка на проверке. При сомнении — `review`.
- Правила нормализации, сокращения, веса и пороги — в `config/` (TOML), не в коде.
- Языки: продукт (веб, воркер, алгоритм, CLI) — только Rust. Python — только офлайн-скрипты в `scripts/` (синтетика, оценка, графики). Логику сопоставления в Python не дублировать: скрипты вызывают CLI `matcher` (см. `SPEC.md`, раздел 7).
- `matcher-core` не зависит от БД и веба.
- Каждый модуль конвейера покрывается тестами. Перед коммитом должны проходить `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, а при изменениях в `scripts/` — `pytest`.
- Если меняешь SQL-запросы `sqlx`, обнови офлайн-метаданные (`cargo sqlx prepare`), иначе сборка в Docker сломается.
- Спорные решения, не описанные в `SPEC.md`, не принимай молча: предложи варианты и спроси.
- Если требование в `SPEC.md` кажется ошибочным или противоречивым — скажи об этом прямо, не подстраивайся.

## Безопасность

- Никогда не записывай секреты (пароли, ключи, токены) в код, коммиты, логи или сообщения. Только `.env` на сервере; в репозитории — `.env.example` с пустыми значениями.
- Не выполняй на сервере разрушительные команды (удаление данных, `DROP`, перезапись томов, изменение настроек SSH или файрвола) без явного подтверждения.
- Все запросы к данным фильтруются по `organization_id` текущего пользователя.

## Окружение

- Не задавай `ANTHROPIC_API_KEY` в общем окружении терминала: иначе Claude Code начнёт тратить баланс API вместо подписки. Ключ будущей языковой модели сервиса называется `LLM_API_KEY` и живёт только в `.env` приложения.
- Целевой сервер: Debian 12, Docker Compose, Caddy (см. `SPEC.md`, раздел 10).
